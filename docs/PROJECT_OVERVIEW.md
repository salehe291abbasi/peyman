# Project overview

Peyman is a Persian, RTL school-services frontend. Its first product focus is coordinating educational trips, from planning through return. The broader vision includes school food/canteen reservations, supplies and rewards, and reviewed school transport services.

Primary audiences: school managers/trip coordinators, parents, destination/transport/food suppliers, and organizational supervisors.

## Current product

An interactive marketing landing page: educational-experience filters and sample details, trip-stage preview, role-specific explanations, guided demo, future-services section and FAQ. Examples are not bookable inventory.

## Actual stack

- Next.js 16.4.6 App Router; React/React DOM declared `^19.2.0`.
- TypeScript strict mode; CSS with shared design tokens and responsive breakpoints.
- Lucide React icons; locally bundled variable Vazirmatn font; local WebP assets and Next Image.
- npm lockfile; Prettier; scripts for development, build, production start, typecheck and formatting.

## Boundaries

Only frontend work is in scope; backend belongs to another developer. There is no real authentication, API integration, reservation, payment or messaging. Future services are roadmap items. Organization/legal policies in supplied PDFs are proposals until confirmed. This is a local preview with indexing disabled, not a publicly launched service.
