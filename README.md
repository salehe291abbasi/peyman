# پیمان

فرانت‌اند فارسی و راست‌به‌چپ سامانه پیمان، ساخته‌شده با Next.js و TypeScript.

کد برنامه در `web/` و مستندات وضعیت پروژه در `docs/` قرار دارند.

```powershell
cd web
npm ci
npm run dev
```

برای بررسی نوع‌ها `npm run typecheck` و برای ساخت نسخه تولید `npm run build` را در `web/` اجرا کنید.

این نسخه نمایشی است و به بک‌اند، احراز هویت، پرداخت یا ارسال پیام متصل نیست. راهنمای بیشتر در `web/README.md` آمده است.
