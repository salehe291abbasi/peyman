# پیمان — فرانت‌اند

لندینگ فارسی و راست‌به‌چپ پیمان، با Next.js App Router و TypeScript. این پروژه فقط فرانت‌اند است و بک‌اند، پرداخت، ثبت‌نام و ارسال پیام واقعی ندارد.

## اجرا

Node.js سازگار با Next.js 16 و npm لازم است. نسخه‌های نصب‌شده در `package-lock.json` ثبت شده‌اند.

```powershell
npm ci
npm run dev
```

آدرس محلی: http://127.0.0.1:3000

```powershell
npm run typecheck
npm run build
npm start
```

## ساختار

- `src/app`: صفحه، چیدمان، metadata، favicon و CSS واکنش‌گرا.
- `src/components/landing.tsx`: تعاملات لندینگ، فیلتر، تب‌ها و دمو.
- `src/components/brand.tsx`: نشان مفهومی پیمان.
- `src/lib/content.ts`: محتوای فارسی، نقش‌ها، مراحل و نمونه‌های تجربه؛ مستقل از JSX.
- `public/images`: تصاویر محلی؛ بدون وابستگی به سرویس عکس هنگام بازدید.
- `docs/design-research.fa.md`: تحقیق تطبیقی و منطق طراحی.
- `docs/assets.md`: منشأ تصاویر و پرامپت تصویر اصلی.
- `docs/verification.md`: نتیجهٔ بررسی‌ها و محدودیت‌ها.

## کتابخانه‌ها

- Next.js و React: رندر اولیهٔ HTML و تعاملات.
- TypeScript: کنترل نوع‌ها و قراردادهای محتوایی.
- Lucide React: آیکن‌های سبک و هماهنگ.
- Fontsource Variable Vazirmatn: فونت فارسی محلی با وزن متغیر.
- CSS: توکن‌های رنگ، چیدمان، واکنش‌گرایی و حرکت محدود؛ فعلاً نیازی به کتابخانهٔ انیمیشن یا مدیریت حالت سراسری نیست.

## وضعیت محصول

تجربه‌ها، چک‌لیست‌ها و درصدهای تکمیل دادهٔ نمایشی‌اند. هیچ ادعایی دربارهٔ مشتری واقعی، مجوز سازمانی یا تعداد کاربران وجود ندارد. خدمات آینده با برچسب «در چشم‌انداز توسعه» متمایزند.

عنوان، توضیح، زبان، viewport و Open Graph در layout تعریف شده‌اند. برای پیش‌نمایش، `noindex, nofollow` فعال است. پیش از انتشار عمومی باید دامنهٔ واقعی، canonical، تصویر اشتراک‌گذاری، sitemap و سیاست ایندکس مشخص شوند. بدون دامنهٔ تأییدشده URL ساختگی تولید نشده است.

## اتصال آینده به بک‌اند

برای اتصال، ابتدا قرارداد OpenAPI، احراز هویت و نشست، خطاها، مجوزها و عملیات مجاز را با توسعه‌دهندهٔ بک‌اند مشخص کنید. محتوای عمومی و داده‌های پنل باید مرز جدا داشته باشند. کنترل مجوز واقعی، اعتبار مدارک، رزرو اتمیک و رضایت قابل استناد در مسئولیت API است. منطق نمونهٔ لندینگ نباید جایگزین آن‌ها شود.
